# AutomationScan

Free browser-based business automation opportunity scanner.

## Deployment
This repository is a static website. GitHub Pages can publish it automatically using the included GitHub Actions workflow.

Before collecting leads at scale, replace the placeholder blueprint email in index.html, choose a domain, and review the privacy notice for your actual services.

The scanner's calculations run in the visitor's browser. The Netlify form attributes are included for optional Netlify Forms use.
